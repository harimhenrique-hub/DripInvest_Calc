# DripInvest_Calc
Open source tool to calculate the necessary investment for a drip irrigation project using three approach as Random Forest, PCA and multi linear regression with different levels of predictors.
This calculator take a value reference for material cost and not bilding and assembly.

The online version can be acessed by the link: https://harim-baldi-modelling.shinyapps.io/app_rlI_rf_IV_pcaI/

The offline version can be downloaded from this material in Releases as the code to create the App.
